# Lesion OS for Waveshare ESP32-S3-ePaper-1.54G V2

**Manufacturer:** Waveshare  
**Exact hardware model:** ESP32-S3-ePaper-1.54G  
**Hardware revision:** V2  
**Processor:** ESP32-S3  
**Display:** 1.54-inch 200 × 200 four-color e-paper (black, white, red, yellow)

## Compatibility

This directory is **only** for the **Waveshare ESP32-S3-ePaper-1.54G V2** board. Do not use these firmware images on other Waveshare 1.54-inch displays, other revisions, or unrelated ESP32-S3 boards.

## Update methods

- **USB recovery / initial installation:** requires a complete merged flash image for this exact board.
- **On-device Wi-Fi OTA:** will download a device-specific OTA application image after checking the update manifest and obtaining user confirmation. It must never flash a merged USB image as an OTA application.

## Availability

**No verified downloadable release has been published here yet.** The device-side updater and automated publishing are under development. Firmware and a machine-readable manifest will be added after build validation.

## Planned files

- `manifest.json`: exact hardware identity, release version, verified HTTPS firmware URL, firmware size and SHA-256 checksum.
- `firmware/`: published device-specific update images and versioned releases.

The Lesion OS source repository remains private.
